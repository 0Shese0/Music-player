# 🎵 Music Player

Музыкальный плеер на Python + PySide6 с современным стеклянным интерфейсом.

## Возможности

- 🎨 4 темы + палитра цветов (акцент, панели, поиск, текст песни)
- 🖼️ Фоновое изображение окна с реальной прозрачностью панелей
- 📁 Несколько плейлистов + закреплённые «Понравившиеся»
- 🔍 Поиск по названию и исполнителю
- 📄 Текст песни с отдельной панелью (сохраняется автоматически)
- 🎵 Поиск на Genius в один клик (с переключателем интернета)
- 📊 Отчёты: итоги дня / недели / месяца
  - Круговые диаграммы топ-треков и топ-исполнителей
  - Время, количество треков, сравнение с прошлым периодом
  - Столбчатая активность по часам/дням
- 💾 Полное сохранение состояния между запусками

## Установка

### Вариант 1: Готовый exe

Скачай `MusicPlayer.exe` со страницы [Releases](../../releases) и запусти.

### Вариант 2: Из исходника

```powershell
pip install PySide6 mutagen
python music_player.py
